# Руководство пользователя Volna

Нативная лаборатория на Rust для двумерных электромагнитных волн: поля **Ez, Hx, Hy**, вакуум, идеальные проводники PEC и поглощающая граница CPML. Можно менять волноводы и отражатели, задавать токи формулами или таблицами, наблюдать поле и записывать показания зондов.

Это самостоятельная 2D TMz-модель, а не произвольный срез трёхмерного устройства. Материалы с диэлектрической проницаемостью, потери металла, движение тел, портовые S-параметры и 3D-эффекты здесь не моделируются.

## Запуск

Нужны установленный Rust **1.96.1**, зависимости из `Cargo.lock` и графическая среда, поддерживаемая `wgpu`. Окно запускается через `eframe`; браузер, сервер и API-ключи не нужны.

В `rust-toolchain.toml` закреплён toolchain `1.96.1`. При использовании rustup обычный `cargo` может загрузить его, если он ещё не установлен. Команды ниже выполняются из корня репозитория:

```bash
cargo run --locked --release
cargo run --locked --release -- --scene presets/waveguide_bend_10ghz.json
cargo run --locked --release -- --scene presets/interference_10ghz.json --view rms
```

`release` предпочтителен для интерактивного расчёта. После сборки приложение можно запускать непосредственно как `target/release/volna`. Параметры `--scene <путь>` и `--view ez|abs|rms` задают начальную сцену и отображение; `--help` выводит справку без открытия окна. Ошибки параметров или файла сцены дают сообщение и ненулевой код выхода, без молчаливой замены сцены. Путь также можно изменить в поле **JSON** внутри окна.

В окружении, где версия 1.96.1 уже установлена под alias `stable`, допустим `RUSTUP_TOOLCHAIN=stable`, но сначала проверьте точную версию через `rustc --version`. Сам по себе alias не закрепляет воспроизводимую версию.

Основные версии GUI/формул: `eframe = 0.36.2`, `egui_plot = 0.37.0`, `evalexpr = 11.3.1`. Используется MIT-версия `evalexpr 11.3.1`; версия 13 с AGPL не подключена. Полный набор разрешённых версий записан в `Cargo.lock`.

## Первый опыт

1. При старте уже работает интерференционная сцена в быстром режиме. Нажмите **«Пауза»**, если хотите сначала осмотреть или изменить параметры.
2. Волновод шириной 22 мм и длиной 80 мм возбуждает сигнал 10 ГГц. Перед ним расположены **шесть разнесённых наклонных PEC-рёбер**, отражённые волны от которых пересекаются с падающим полем в общей области. Три зонда стоят около `(235, 150)` мм и на 20 мм выше/ниже. Сцена сохранена в [`presets/interference_10ghz.json`](../presets/interference_10ghz.json).
3. Для явной загрузки введите этот путь в **JSON** и нажмите **«Открыть»**. Относительные пути считаются от рабочего каталога процесса. Простой исходный волновод без рёбер по-прежнему доступен в [`presets/waveguide_10ghz.json`](../presets/waveguide_10ghz.json).
4. Выберите волновод на поле или в списке **«Объекты»**. Положение и угол меняются сразу — мышью или координатами в инспекторе, без перезапуска поля. Для остальных параметров используйте **«Применить и сбросить»**.
5. **«Запуск» / «Пауза»** управляют продвижением физического времени. **«Один шаг»** доступен на паузе. **«Сброс поля»** обнуляет поля, память CPML, время, RMS и историю зондов для последней принятой сцены.
6. Смотрите карту **Ez**, **|Ez|** или **RMS(Ez)**; внизу находится **«Зонды · Ez(t)»**. Для сохранения данных задайте путь CSV и нажмите **«Экспорт новый»**.

Применение сцены и сброс сохраняют режим запуска/паузы. Чтобы исследовать состояние от самого начала, сначала поставьте расчёт на паузу, затем сбросьте его и используйте одиночные шаги.

В стартовом примере каждое ребро имеет размер 24×2 мм. Между рёбрами оставлены промежутки; они не замыкают общую область в резонатор, и волна может уходить к CPML. Смотрите **Ez** для фазовой картины и **RMS(Ez)** для усреднённого по полному окну пространственного рисунка; завершение окна само по себе не означает, что переходный процесс закончился. Это учебный пример интерференции и дифракции, не обещание идеального фокуса или измеренного усиления мощности.

## Г-образный волновод

Нажмите **«+ Г-волновод»** и укажите положение в сцене. Канал поворачивает на 90°; обе части имеют общую ширину и толщину PEC-стенок. В инспекторе доступны длины первого и второго плеча; смена формы и длин применяется через **«Применить и сбросить»**. Положение и поворот всей конструкции изменяются без перезапуска, как у прямого волновода. Выбирать и перетаскивать можно за любое из двух плеч.

Готовый пример: [`presets/waveguide_bend_10ghz.json`](../presets/waveguide_bend_10ghz.json). Введите путь в поле JSON и нажмите **«Открыть»**. В нём два плеча по 80 мм, канал 22 мм, сигнал 10 ГГц и зонды во втором плече и за выходом. Источник стоит на первом плече, задний торец закрыт, выход второго открыт. Острый угол может отражать часть волны — это не согласованный безотражательный переход.

## Управление сценой

| Действие | Управление |
|---|---|
| Выбрать объект | Инструмент **«Выбор»**, щелчок по объекту или строке в списке |
| Переместить | Перетащить объект левой кнопкой |
| Повернуть | Перетащить круглую ручку выбранного волновода/отражателя |
| Изменить размеры | Поля инспектора; единицы указаны у каждого поля |
| Добавить | **«+ Волновод»**, **«+ Г-волновод»**, **«+ Отрезок»**, **«+ Прямоугольник»**, **«+ Круг»**, **«+ Зонд»**, затем щелчок в сцене |
| Нарисовать ломаную | **«+ Ломаная»**, щелчки по вершинам; двойной щелчок или Enter завершает, Esc отменяет |
| Копировать / удалить | **«Дублировать»** / **«Удалить»** в инспекторе; Delete при фокусе поля удаляет выбранный объект |
| Масштабировать / панорамировать | Колесо; правая/средняя кнопка мыши, либо **«Камера»** и левая кнопка |
| Вернуть общий вид | **«Вписать»** |
| Читать значения по узлам | Курсор над полем; после фокуса поля стрелки перемещают точку чтения, а не объект |

**Положение и угол существующих объектов применяются во время перетаскивания**, а также при изменении координат/угла в инспекторе. Промежуточные положения поступают в worker с ограниченной частотой; отпускание мыши досылает окончательное положение и **не сбрасывает поле**. При работающей симуляции волна продолжает распространяться. На паузе геометрия меняется, но расчёт сам не запускается и физическое время не продвигается. Перенос зонда меняет только точку измерения, не поля.

Размеры, сетка, формулы и остальные параметры сначала меняют **черновик**. Их принимает кнопка **«Применить и сбросить»**. Перемещение передаёт только положение/угол и не применяет заодно другие правки. Добавление, удаление и копирование объектов остаются операциями создания сцены с нулевым полем. **«Отменить правки»** восстанавливает принятую сцену и также сбрасывает расчёт.

Live-перестройка сохраняет время, H и память CPML; Ez обнуляется только на новой PEC-маске. Это **не моделирование движущегося металла или Доплера**. После переноса остаются переходные поля от прежней конфигурации. Для независимого расчёта новой статической сцены нажмите **«Сброс поля»**. Уже закончившийся импульс сам не повторится от перемещения источника.

**Почему отражённая рябь не исчезает сразу?** Вакуум и PEC в этой модели не имеют потерь. CPML поглощает волну только у внешних границ области, а не внутри волновода. Уже отражённый пакет остаётся в поле после переноса отражателя и может ещё многократно отражаться от остальных стенок; непрерывный источник продолжает вносить энергию. В полностью замкнутой идеальной полости незатухающие колебания ожидаемы. Удаление старой PEC-маски не должно удалять уже отражённую волну. Общего искусственного затухания нет: реальные потери металла/среды требуют отдельной модели и параметров. Для сравнения новой статической геометрии без памяти прежнего движения используйте явный сброс.

Неверное положение не заменяет последнюю корректную геометрию и не останавливает исправный работающий расчёт. Принятые контуры соответствуют показываемому полю, а неприменённое положение обозначается отдельно. При добавлении выберите инструмент **«+ …»**, затем щёлкните в поле: **пунктирный черновой контур появляется сразу**, ещё до подтверждения worker. Это предварительное размещение, не принятая PEC-маска; после подтверждения появляется обычный контур. Отклонённый объект остаётся видимым как черновик с диагностикой, а не исчезает без объяснения. Явные Apply/Load/Reset отменяют незавершённое перетаскивание: запоздавшее отпускание мыши не переносит объект в уже другую сцену.

Не сбрасывают расчёт: камера, тема, Ez/|Ez|/RMS, авто/ручная шкала, **«Скрыть CPML»**, **«PEC-ячейки»**, **«Сетка осей»**, **«Штрихи ±»** и выбор графиков. **«Шагов/пакет»** задаёт предел 1–128 физических шагов в пакете; по умолчанию выбран быстрый режим **128**. Пакет также ограничен бюджетом около 8 мс с проверкой после каждого шага, поэтому фактическое число шагов может быть меньше. Это скорость проигрывания, **не изменение скорости света, CFL или физического dt**. Для интерактивной работы используйте release-сборку: dev значительно медленнее.

## Источники и измерения

- **J₀ измеряется в А/м².** Это плотность тока, не заданная амплитуда Ez, напряжение или мощность.
- Инспектор показывает размеры в мм, частоты в ГГц, задержку в нс, общую фазу в градусах. В JSON и формулах используются метры, секунды, герцы и радианы.
- Временные сигналы: CW с плавным стартом, Gaussian, формула, таблица. Амплитуда и добавочная фаза по апертуре выбираются независимо.
- Переменные формул: `t` — секунды после задержки, `s` — апертурная координата от −1 до 1, `f` — Гц, `phi` — радианы, `pi`. `1/2` означает 0.5. Семантика фазы и допустимые функции описаны в [модели сцены](model.md).
- Таблица вводится двумя колонками через пробел, с десятичной точкой. Нажмите **«Принять точки в черновик сцены»**, затем **«Применить и сбросить»**. Таблица времени вне своего интервала равна нулю; повторение включается только явным флажком **«Периодически (проверять стык)»**.
- **«Предпросмотр Jz(t) и апертуры»** показывает ток источника, а не рассчитанное Ez. Предпросмотр ограничен 256 временными и 129 пространственными точками и не проверяет спектральную полосу.
- `f_max` — заявленная пользователем верхняя значимая частота. Проверяется разрешение сетки для этого числа, но спектр произвольной формулы или таблицы автоматически не доказывается.
- Отключение **«Источник включён»** выключает ток, но оставляет PEC-стенки волновода.

Зонды измеряют Ez в ближайшем узле сетки. Фактическая координата узла видна в режиме **«Таблица»**. Можно показать до трёх закреплённых зондов или выбранный зонд. Отрисовка содержит не более 4096 точек на кривую; экспорт использует доступную историю worker, а не только точки графика. История ограничена 100 000 синхронных кадров: старые кадры вытесняются. При принятом изменении положения любого объекта начинается **новый общий сегмент истории зондов**, чтобы отсчёты прежней позиции/геометрии не подписывались как новые измерения. Это очистка измерений, не сброс поля или времени. На паузе новые отсчёты не добавляются.

RMS рассчитывается по физическим неперекрывающимся окнам, независимо от FPS. До окончания первого окна карта не подменяется частичным результатом: видна надпись **«Ожидание первого завершённого окна RMS»**. Затем показывается последняя завершённая карта, а процент заполнения относится к следующему окну. Длительность окна задаётся в **«Область, сетка и RMS»**; её изменение требует применения сцены.

Перенос волновода или отражателя начинает новое окно RMS; перенос зонда полевой RMS не сбрасывает. Если после live-правки выбран RMS, но новая карта ещё не готова, временно показывается **Ez** с явной подписью **«Ez; RMS накапливается»** и шкалой Ez. После полного окна интерфейс возвращается к RMS. При непрерывном движении окно может не успевать завершиться — прежняя карта не выдаётся за результат новой геометрии.

## JSON и CSV

**JSON — сцена для холодного старта, не checkpoint.** Он не содержит накопленных полей, памяти CPML, текущего времени и истории. **«Сохранить новый»** сохраняет валидный черновик сцены, даже если тот ещё не применён к расчёту. Успешное **«Открыть»** заменяет сцену и начинает её с нулевого состояния.

**«Сохранить новый»** / **«Экспорт новый»** не заменяют существующий файл. **«Перезаписать…»** / **«Заменить CSV…»** требуют отдельного подтверждения с точным путём. Запись идёт через соседний временный файл; отказ от перезаписи защищён и от конкурентного создания целевого файла.

Перед публикацией сбрасываются пользовательский буфер и файл через `sync_all`; на Unix после публикации синхронизируется родительский каталог. Читатель видит целиком старый или новый файл, а не промежуточную запись. Это **не абсолютная гарантия сохранности при отключении питания**: поведение накопителя/файловой системы и платформенные гарантии отличаются. Без перезаписи требуется поддержка hard links; небезопасного fallback нет. Если файл уже опубликован, но файловая система не позволяет синхронизировать каталог, возвращается явное сообщение **«Файл … опубликован, но синхронизация каталога … не выполнена»**. Это не означает, что файла нет; проверьте результат перед повторной записью. Очистка временного имени после публикации выполняется best-effort и сама по себе не отменяет успешную запись.

CSV, экспортированный из GUI, начинается строкой:

```text
# metadata: {"...":"компактный JSON метаданных запуска"}
```

Это **комментарий перед CSV**, а не строка табличных измерений. CSV-reader должен сначала пропустить/разобрать её, затем читать заголовок `time_s` и колонки `Ez_V_m:имя_зонда`. Время — секунды, Ez — В/м. Имена заключены в кавычки, экранируются и получают безопасный префикс от интерпретации как формул электронной таблицы.

Метаданные содержат принятую сцену, её SHA-256, версию решателя, поколение сцены и принятую revision/run, шаг и физическое время, `dt`, версию компилятора, target, профиль сборки, ОС, число потоков решателя, состояние исходной ревизии и лимит истории. Окно RMS входит в сцену. Начало текущего измерительного сегмента записывается отдельно; `inherited_fields=true` отмечает, что в данном запуске менялась EM-геометрия без обнуления поля. Перенос одного зонда этот признак не устанавливает и не снимает уже установленный. Он сбрасывается при новом холодном запуске.

Конечная сцена в таком CSV **не воспроизводит переходное поле сама по себе**: полный журнал живых перемещений и checkpoint полей не сохраняются. Для воспроизводимого сравнения статических конфигураций после редактирования выполните явный сброс. Если исходники не находятся в Git, метка ревизии — `unversioned`, а не выдуманный commit. CSV относится к **активной** сцене worker, не к неприменённому черновику UI.

## Проверки и устройство проекта

Следующие команды — процедуры проверки, **не утверждение, что проверки уже прошли в вашей среде**. При использовании rustup выбирается версия из `rust-toolchain.toml`; зависимости не обновляются:

```bash
# Ядро и интеграционные тесты без GUI
cargo test --workspace --locked --no-default-features
cargo test --workspace --locked --release --no-default-features

# Включая штатную GUI-feature
cargo test --workspace --locked
cargo test --workspace --release --locked
cargo clippy --workspace --all-targets --locked -- -D warnings

# Форматирование: только проверка, без изменений
cargo fmt --all -- --check
```

- [`docs/model.md`](model.md) — параметры сцены, единицы, источники, формулы и ограничения входов.
- [`docs/numerics.md`](numerics.md) — численная схема, границы, RMS и проверяемые источники метода.
- [`docs/validation.md`](validation.md) — отчёт с фактически выполненными научными и интеграционными проверками и их ограничениями.
- `src/model` — сериализуемая сцена и геометрия; `src/sources.rs` — подготовленные сигналы; `src/solver` — вычислительное ядро; `src/runtime.rs` — worker и воспроизводимый экспорт; `src/ui` — нативное окно.
