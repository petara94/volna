# Сцена и источники

Этот документ задаёт пользовательский контракт сцены: величины, координаты, входные ограничения и смысл источников. Формулы обновления полей, коэффициенты CPML и методика проверки ядра находятся отдельно в [numerics.md](numerics.md); здесь они не дублируются.

## Физический смысл

Модель двумерная, однородная по z, с компонентами Ez, Hx, Hy. Область заполнена вакуумом. Волноводы и отражатели — идеальные проводники PEC; внешняя область может иметь CPML. Между интерактивными правками геометрия неподвижна.

Перемещение и поворот существующих объектов — отдельные live-операции: они сохраняют физическое время, поля вне новой PEC-маски, магнитное поле и память CPML. Поле реагирует на принятые промежуточные положения во время перетаскивания. На паузе смена положения не продвигает физическое время и не включает расчёт. Ток перемещённого волновода продолжает использовать прежнее время: CW ramp, задержка и импульс не стартуют заново. Уже завершившийся импульс переносом не повторяется.

Это интерактивная перестройка маски, **не физическая модель движущегося проводника**. Скорость мыши не задаёт скорость металла; Доплер, работа перемещения и сохранение энергии через правку не моделируются. Переходное поле содержит память предшествующей конфигурации. Для расчёта новой статической сцены с нулевых начальных условий служит явный сброс.

Добавление/удаление объектов, применение размеров, сетки и параметров сигнала, а также загрузка JSON остаются операциями холодного старта. Перенос не применяет заодно такие непринятые изменения из инспектора. Неверное положение не заменяет принятую геометрию и не останавливает исправный работающий расчёт.

Источник задаёт **плотность электрического тока Jz**, а не Ez и не мощность. Нормировка `current_a_m2 = 1` не означает поле 1 В/м и не задаёт мощность в ваттах. Поле является результатом решения с данным распределением тока и геометрией.

Нет произвольных диэлектриков, потерь в металле, движения проводников, 3D-портов или расчёта S-параметров. Сравнение с реальным экспериментом требует отдельной валидации модели.

Внутри вакуумной области нет общего коэффициента затухания: PEC отражает без омических потерь, а CPML поглощает только поле, достигшее внешнего слоя. После переноса отражателя ранее отражённые E/H не исчезают; они продолжают распространяться в новой геометрии. Непрерывное возбуждение поддерживает поле, а полностью замкнутая идеальная полость допускает незатухающие моды. Продолжительность ряби сама по себе не доказывает наличие старой маски или дефект CPML. Ускорение проигрывания меняет число расчётных шагов на единицу реального времени, но не c₀, CFL или физический dt.

## Единицы и координаты

В JSON и вычислительном API используется SI:

| Величина | Единица |
|---|---|
| Координаты, размеры, шаг сетки | м |
| Время, задержка, ширина импульса | с |
| Частоты `frequency_hz`, `fmax_hz` | Гц |
| `current_a_m2` | А/м² |
| Ez и его RMS | В/м |
| Hx, Hy | А/м |
| `phase_rad` и значения фазового профиля | рад |
| `angle_deg` геометрического поворота | градусы |
| Нормализованная апертурная координата `s` | безразмерная, −1 ≤ s ≤ 1 |

Интерфейс переводит расстояния в мм, время в нс, частоты в ГГц и общую фазу в градусы. **Это не меняет единиц текста формул и таблиц.** Например, временная таблица `0.1 1` задаёт 0.1 секунды, не 0.1 нс; для 0.1 нс нужно `1e-10 1`.

Начало глобальных координат находится в левом нижнем углу полезной области; x направлена вправо, y вверх. У каждого волновода/отражателя есть локальная система, повёрнутая на `angle_deg` против часовой стрелки вокруг `center`.

## Структура JSON

Версия схемы — `schema_version: 1`. Неизвестные поля, неподдерживаемые версии, неверные варианты `kind` и некорректные параметры отклоняются. Файл сцены ограничен **8 МиБ**. Готовый полный пример — [`../presets/waveguide_10ghz.json`](../presets/waveguide_10ghz.json); интеграционный тест сравнивает его с `Scene::default()` и проверяет сохранение/загрузку.

| Поле сцены | Содержание |
|---|---|
| `domain` | Размер полезной области, квадратный шаг сетки, CFL, толщина CPML в ячейках |
| `sources` | Волноводы, их PEC-стенки и параметры токов |
| `reflectors` | PEC-отрезки, прямоугольники, круги или ломаные |
| `probes` | Идентификатор, имя и требуемая координата зонда |
| `rms_window_s` | Длительность физического окна RMS |

Идентификаторы источников, отражателей и зондов уникальны во всей сцене; 0 и `u64::MAX` запрещены. Имена — 1–256 байт UTF-8 без управляющих символов. JSON хранит настройки для **холодного старта**: полей и истории в нём нет.

### Область

`domain.width_m` и `height_m` — размеры полезной области без CPML, `cell_m` — общий шаг по x и y. Размеры должны быть кратны шагу с допустимой погрешностью представления чисел. Значение `cfl` строго между 0 и 1.

`pml_cells` принимает 8–64 либо 0. При 0 внешняя граница замкнута PEC; это не открытое пространство. При положительном значении CPML добавляется снаружи полезной области, а его внешний край также замкнут PEC. Переключатель **«Скрыть CPML»** только обрезает изображение и не выключает слой.

### Волновод

`center` — середина первого прямого участка; для прямого волновода это геометрический центр всей конструкции. Продольная ось входного участка — локальная x′. У прямого волновода при нулевом повороте открытый конец направлен вправо; поворот выхода Г-канала описан ниже.

- `width_m = a` — внутренняя ширина канала между PEC-стенками по y′.
- `length_m = L` — длина от x′ = −L/2 до x′ = L/2.
- `wall_m` — толщина боковых стенок и, если включена, задней стенки.
- `closed_back` — наличие задней PEC-стенки у x′ = −L/2.
- `source_offset_m` — расстояние от заднего края до центра полосы тока.
- `strip_m = d` — **физическая** продольная толщина полосы тока, не число ячеек.
- `enabled` выключает ток, но не удаляет PEC-геометрию волновода.

Центр полосы тока имеет координату `x_src = −L/2 + source_offset_m`. Для точки внутри полосы вводятся `n = x′ − x_src` и `s = 2 y′ / a`.

### Г-образный канал

Необязательное поле `bend` задаёт единственный поворот на 90°:

```json
"bend": { "length_m": 0.08 }
```

Отсутствующее поле или `null` означают прежний прямой волновод. При `bend = None` поле не включается в сохраняемый JSON; прежний прямой пресет остаётся совместимым. `schema_version` остаётся 1. Старый бинарник, не знающий `bend`, отклонит файл с этим полем, а не молча заменит Г-канал прямым.

При наличии `bend` прежнее `length_m = L1` — длина первого плеча по центральной линии от `(−L1/2,0)` до `(L1/2,0)`. Второе плечо идёт вдоль **+y′** от колена `(L1/2,0)` до открытого выхода `(L1/2,L2)`, где `L2 = bend.length_m`. `center` по-прежнему означает середину первого плеча, не центр bounding box всей конструкции. Поворот `angle_deg` вращает оба плеча вместе.

Четыре прямоугольные PEC-стенки образуют острый угол без перегородки поперёк канала. Ширина `width_m` и толщина `wall_m` одинаковы в обоих плечах. `closed_back` управляет прежним входным торцом первого плеча; выход второго плеча открыт. Полоса источника остаётся на первом прямом участке с прежними `source_offset_m`, `strip_m` и поперечной координатой s.

Оба плеча должны быть не короче `a/2 + wall_m + 2h`. Для источника дополнительно требуется `source_offset_m + strip_m/2 ≤ L1 − a/2 − h`: полоса отделена от колена минимум одним шагом. Проверяются реальные вершины повёрнутой Г-геометрии, а не углы прямоугольника, заполняющего её выемку. Пример с двумя зондами — [`../presets/waveguide_bend_10ghz.json`](../presets/waveguide_bend_10ghz.json).

Смена `bend` или длины плеча требует холодного применения сцены. Перенос и поворот всей конструкции — live-операции. Порог `fc = c0/(2a)` характеризует прямые участки, но сам по себе не задаёт коэффициент передачи/отражения в колене; согласование изгиба и S-параметры не заявляются.

### Отражатели и зонды

В `shape.kind` допустимы:

- `Segment`: `length_m`, `thickness_m`; конечная толщина, с округлёнными концами по геометрическому тесту расстояния.
- `Rectangle`: `width_m`, `height_m`; заполненная PEC-область.
- `Circle`: `radius_m`; заполненная PEC-область.
- `Polyline`: `points` в локальных метрах и `thickness_m`; порядок точек задаёт последовательность сегментов, монотонность координат не требуется.

Зонд задаётся непрерывной координатой `position`, но измеряет Ez в ближайшем узле сетки. Фактический узел отображается в таблице зондов. В PEC-узле Ez равно нулю, поэтому для измерения поля в вакууме зонд нужно разместить вне проводника. При измельчении сетки положение ближайшего узла может измениться.

Перенос зонда обновляет индекс измерения без воздействия на поля/CPML/RMS. При принятом перемещении любого объекта начинается новый общий сегмент синхронной истории всех зондов; новые отсчёты появляются после следующих успешных физических шагов. Изменение источника или PEC также начинает новое полевое окно RMS, но не обнуляет физическое время. JSON по-прежнему задаёт холодный старт и не хранит предшествующую траекторию live-редактирования.

## Полный ток источника

Обозначим `J0 = current_a_m2`, `τ = t_seconds − delay_s`, `φ0 = phase_rad`. Источник равен нулю до своей задержки и при `enabled = false`.

В активной полосе:

```text
φ(τ,s) = φ0 + P(τ,s,f,φ0)
Jz(t,n,s) = J0 · W(n) · A(τ,s,f,φ) · q(τ,s,f,φ)

W(n) = cos²(pi*n/d),  |n| < d/2
W(n) = 0,             вне полосы
```

Здесь `P` — `phase_profile`, `A` — `aperture`, `q` — `signal`, `f = frequency_hz`. Геометрия ограничивает ток внутренностью канала; PEC-узлы и края полосы не возбуждаются. Для преобразования координат используется только малый допуск roundoff, не дополнительная физическая толщина.

`CompiledSource::value(t_seconds, s)` возвращает `J0·A·q`, то есть ток в центре продольного окна, где W = 1. Решатель отдельно умножает его на предварительно рассчитанный геометрический вес W(n). При проверках измельчения сетки `strip_m`, `current_a_m2` и остальные физические размеры сохраняются; нельзя незаметно заменять фиксированную толщину полосой в одну ячейку.

Ширина `a`, частота и масштаб тока независимы. Справочные значения отсечек, выводимые инспектором, относятся к идеальному прямому каналу: `fc1 = c0/(2a)`, `fc2 = c0/a`; это не измерение спектра конечной открытой сцены.

## Временной сигнал `signal`

Все сигналы используют локальное время **τ после задержки**. Для τ < 0 выражения не вычисляются и ток равен нулю. Частота и заявленный `fmax_hz` должны быть конечными положительными числами; `fmax_hz ≥ frequency_hz`, задержка — конечной и неотрицательной. Амплитуда и общая фаза конечны; отрицательная амплитуда допустима и меняет знак тока.

### `Continuous`

Параметр `ramp_periods > 0`, время включения `T = ramp_periods/f`:

```text
q(τ,s) = R(τ) · sin(2*pi*f*τ + φ)
R(τ) = sin²(pi*τ/(2*T)),  0 ≤ τ < T
R(τ) = 1,                τ ≥ T
```

Это raised-cosine включение. Форма sin² с половинным аргументом эквивалентна `(1−cos(pi*τ/T))/2`, но не теряет маленькие амплитуды из-за вычитания близких к единице чисел.

### `Gaussian`

Параметры `center_s ≥ 0`, `width_s > 0`, оба конечны:

```text
q(τ,s) = exp(-0.5*((τ-center_s)/width_s)^2) · sin(2*pi*f*τ + φ)
```

`width_s` — стандартное отклонение Gaussian-огибающей, не FWHM. Общая и пространственная фазы изменяют **несущую**, а не центр/ширину огибающей. Задержка и фаза — разные параметры.

### `Formula`

`expression` непосредственно задаёт безразмерный q. Дополнительная синусоида к результату **не домножается**. Чтобы использовать гармоническую несущую и фазу, их нужно явно включить, например:

```text
sin(2*pi*f*t + phi)
exp(-0.5*((t-5e-10)/1.5e-10)^2) * sin(2*pi*f*t + phi)
```

Здесь `t` — именно τ, секунды после задержки. Формула может зависеть от `s`; например, `cos(pi*s/2)` является постоянным во времени q, а не автоматически модулированным сигналом частоты f.

### `Table`

`samples` — пары `[t_seconds, q]`, 2–4096 точек. Координаты строго возрастают, все числа конечны. Используется линейная интерполяция, не spline.

- `periodic: false`: вне первого/последнего времени q = 0.
- `periodic: true`: период равен разности последнего и первого времени; значения q на концах должны **точно совпадать**, иначе таблица отклоняется.
- `phase_rad` и `phase_profile` не превращаются в искусственный сдвиг временной таблицы. Для сдвига всего запуска служит `delay_s`.

## Апертурные профили

`aperture` задаёт безразмерный множитель амплитуды, `phase_profile` — добавку фазы в радианах. Варианты `kind` у них одинаковы:

| `kind` | Значение профиля |
|---|---|
| `Uniform` | 1 |
| `Fundamental` | `cos(pi*s/2)` |
| `Gaussian` | `exp(-0.5*(s/width)^2)`, конечная `width > 0` |
| `Formula` | Результат `expression` |
| `Table` | Линейная интерполяция по s; 2–4096 конечных точек, строгий порядок, диапазон покрывает [−1,1] |

**`phase_profile: {"kind":"Uniform"}` означает добавку 1 рад, не 0.** Синфазная апертура по умолчанию задаётся `{"kind":"Formula","expression":"0"}`. Линейный наклон фазы, например `pi*s/4`, также задаётся формулой фазового профиля.

Переменная `phi` в формуле **фазового профиля** означает исходную `phase_rad`. После вычисления P полученная сумма `φ0 + P` передаётся как `phi` в амплитудный профиль и временной q. Встроенные профили зависят только от s, но пользовательские формулы могут зависеть и от t; поэтому их значения не считаются неизменными пространственными коэффициентами.

## Язык выражений и ошибки

Допустимые переменные — `t`, `s`, `f`, `phi`, `pi`. Числа и все подвыражения вычисляются в **f64**, в том числе литералы без десятичной точки: `1/2 = 0.5`, `sqrt(1/4) = 0.5`.

Арифметика: `+`, `-`, `*`, `/`, `%`, `^`, скобки и унарный минус. Для однозначного задания порядка возведения в степень используйте скобки.

Функции одного аргумента:

```text
sin cos tan asin acos atan exp sqrt abs ln log log10 log2
floor ceil round sinh cosh tanh
```

`log` — синоним натурального `ln`, а `log10` и `log2` имеют указанные основания. Функции двух аргументов: `min`, `max`, `pow`, `atan2`, `hypot`; например `max(0,1-s*s)`. Все тригонометрические углы — в радианах.

Разбор выполняется один раз при подготовке источника. Ограничения: 2048 байт текста, вложенность скобок не более 32, не более 128 арифметических разделителей/операторов до разбора, не более 512 узлов и глубины 32 в AST. Более строгая проверка AST может отклонить выражение, прошедшее предварительную проверку текста.

Нет присваиваний, строк, цепочек через `;`, случайных чисел, I/O и произвольных builtin-функций. Неизвестные переменные и функции отклоняются. Константные ошибки вроде `1/0` отклоняются при подготовке; ошибка области определения, переполнение или NaN/Inf при вычислении дают явную ошибку и останавливают расчёт. Они не подменяются нулём. Корректный конечный результат может округлиться к нулю при underflow f64.

`fmax_hz` — **декларация пользователя**, не доказанный предел спектра. Резкий обрыв таблицы, недостаточно плавное включение или формула с высокими частотами могут содержать значимые компоненты выше fmax. Проверка числа ячеек на заявленную длину волны не устраняет такую ошибку постановки.

## Ограничения входов и ресурсов

| Ограничение | Текущее правило |
|---|---|
| Полезная сторона сетки | От 16 до 8192 интервалов; CPML и граничные узлы добавляются отдельно |
| Шаг `cell_m` | От 10⁻¹² до 10⁶ м; конечный |
| CFL | Строго 0 < CFL < 1 |
| CPML | 0 либо 8–64 ячейки |
| Разрешение на fmax | `c0 / (fmax_hz * cell_m) ≥ 20` |
| Канал волновода | Ширина не менее 6 ячеек |
| Стенки и полоса тока | Толщина не менее 2 ячеек |
| Отражатели | Размеры/толщина либо радиус — не менее 2 ячеек |
| Источники / отражатели / зонды | Не более 16 / 256 / 16 |
| Ломаные | 2–8192 точки на ломаную, суммарно не более 8192; соседние точки разнесены минимум на 2 ячейки |
| Геометрический угол | Конечный, абсолютное значение не более 360 000° |
| Окно RMS | От 1 до 10 000 000 физических шагов |
| История зондов | Последние 100 000 кадров |
| Растеризация | Не более 50 млн расчётных проверок геометрии |
| Источники на шаг | Не более 1 млн условных операций с учётом числа возбуждаемых узлов |
| Оценка пиковых данных | Не более 512 МиБ |

Полоса возбуждения должна целиком помещаться в волноводе, с зазором от стенки/края не менее одной ячейки. Объекты размещаются внутри полезной области с геометрическим запасом; зонды — внутри её границ. Растеризованный источник не должен пересекать PEC и должен содержать хотя бы один возбуждаемый узел.

Оценка памяти консервативно учитывает поля и память CPML/RMS, обе сцены при замене, снимки, разреженные источники и историю при экспорте. Это защитный бюджет внутренних данных, **не измеренный RSS процесса или видеопамять**. Допустимые по отдельности размеры всё равно могут не пройти общий бюджет.

Нарушение входного контракта отклоняется до принятия новой рабочей сцены. В процессе расчёта численная ошибка не публикует частично обновлённое поле: UI сохраняет последний корректный снимок, а для продолжения требуется сброс или новая сцена.
